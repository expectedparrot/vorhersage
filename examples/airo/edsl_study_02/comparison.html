What this replication establishes

Research now happens in rounds

The expanded gate requires 16 successful tool calls, eight distinct search queries, six distinct page URLs, four recency-filtered searches, and a later-turn search after a page read. These are additional enforcement rules, not the authors’ literal ten-call gate. Cached 7,000-character windows let models read further into documents.

Tavily is the closer provider match

The authors used Tavily advanced search and basic extraction. This wave used web.run, with different search ranking, recency semantics and extraction. Firecrawl is not necessary. A Tavily executor is ready for a separately registered run with credentials.

Model settings and failures matter

Astra’s local EDSL adapter drops the requested xhigh parameter; the remote setting is unverified. Its invalid JSON was returned to the model for resubmission without controller edits. Opus exhausted its reduced output allowance on reasoning, so effort was amended from max to high. Fable’s provider refusal ended that session.

Coherence is not predictive accuracy

The final grids are imported and audited without repairs. These are single sessions with a later information date and changed research. To isolate transport or research effects, use repeated paired runs with frozen evidence and verified provider settings.
